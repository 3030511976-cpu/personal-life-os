茶庄 B 端客户数字化

家里的茶叶批发生意做了十几年，客户信息一直散落在微信聊天和纸质本里。我用一个周末把它搬进了表格，又用企微把动作固定下来。

一、客户档案字段

  • 茶庄名称、所在城市、联系人
  • 主营品类：绿茶 / 红茶 / 乌龙 / 普洱
  • 采购频次与单次采购量
  • 价格带与账期习惯
  • 上次寄样时间、上次成交时间

字段不求多，但必须能回答三个问题：谁在买、什么时候会再买、他为什么选我们。

二、企微标签体系

用「城市 + 品类 + 客户等级」三段式打标签，例如：济南-绿茶-A。标签只用于筛选和群发，不做过度细分。

三、样品试喝 SOP

  1. 寄样前确认对方主营品类与价格带
  2. 样品袋贴手写标签：品类、产地、冲泡建议
  3. 签收后 48 小时内回访，只问一个问题：口感上还差什么
  4. 一周内给出对应批次的报价单

四、复购提醒

春茶、秋茶上市前两周，按客户历史采购品类分组触达。不群发广告，只发「今年这批的特点 + 是否留货」。

数字化不是为了显得高级，而是为了让我不在家的时候，这套生意也能按节奏运转。
